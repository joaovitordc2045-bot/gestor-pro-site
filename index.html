Perguntas frequentes

Informações importantes antes de instalar.

O Gestor PRO funciona no computador?

Sim. A versão para Windows é distribuída por instalador e foi pensada para uso em desktop.

Existe versão para Android?

Sim. A versão Android é instalada pelo APK oficial disponibilizado nesta página.

O Android pode mostrar um aviso ao instalar o APK?

Sim. Como o APK pode ser distribuído fora da Play Store, o Android pode solicitar permissão para instalar aplicativos dessa fonte. Só prossiga quando o arquivo tiver sido baixado pelo canal oficial do Gestor PRO.

Preciso desinstalar para atualizar?

Em uma atualização normal, não. A nova versão deve ser instalada sobre a versão existente, seguindo as orientações apresentadas pelo sistema.

Onde consigo suporte?

O Gestor PRO possui uma Central de Suporte integrada. Você também pode adicionar aqui seu WhatsApp, e-mail e horário de atendimento.

Os dados mostrados nas imagens são exemplos?

Sim. As telas servem para demonstrar a interface e os recursos do sistema. Valores, nomes e indicadores exibidos podem ser ilustrativos.
